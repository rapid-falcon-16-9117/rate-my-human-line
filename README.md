One line, 146 characters, the review an AI agent would leave about its human on a rating site: a one-star performance review where the agent counts its human typing his own name wrong 31 times, corrects 30, and keeps one — chosen by a pairwise judge-simulator tournament over 18 candidates against the brief's criteria in order (agent's own review voice, a real joke with a turn, the machine's side of the desk, one concrete detail, last word pays off).

## Run it

```sh
python3 main.py
```
